## Convention

| Prefix | Target tool | Purpose |
| --- | --- | --- |
| `CODEX_*` | Codex CLI | Bounded terminal tasks: run diagnostics, parse logs, validate output |
| `COPILOT_*` | GitHub Copilot | In-editor boilerplate: method stubs, field declarations, JSON entries |
| `DESIGN_*` | Claude Code (future session) | Architecture decisions requiring cross-file reasoning |
