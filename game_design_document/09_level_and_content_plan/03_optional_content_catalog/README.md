# Optional Content Catalog

## Design Position
Optional content should enrich mastery, lore, relationships, and atmosphere without carrying the only route to emotional comprehension.

## Strong Optional Types
- memory echo rooms
- NPC quest rooms
- combat trial rooms
- movement mastery rooms
- hidden relic rooms
- lore tablet chambers
- shortcut unlock rooms
- environmental puzzle rooms
- boss remembrance arenas

## Constraint Rule
Optional content may deepen plateau meaning, but it must not undo core canon, restore Yin and Yang, or replace the main release arc.
