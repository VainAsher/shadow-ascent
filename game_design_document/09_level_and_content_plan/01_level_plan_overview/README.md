# Level Plan Overview

## Design Position
The campaign should read as a finite authored spine supported by elastic content inside narrative plateaus. This branch exists to keep the content plan explicit instead of implying it through story notes alone.

## Current Structure
The strongest current level-plan model is:
- opening home and onboarding in Lantern Heights
- scripted isolation and Hollowing at Summit Shrine
- Hollow Depths recovery arc across multiple boss/ability dungeons
- Ember Monastery support-and-training cluster
- Skyroad ascent using the full kit
- Mirror Summit release beat
- Beacon Cliff ending resolution

## What To Maintain Here
- critical-path ordering
- content density expectations per plateau
- where optional content deepens rather than replaces the main arc
