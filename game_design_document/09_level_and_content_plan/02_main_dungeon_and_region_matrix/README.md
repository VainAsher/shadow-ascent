# Main Dungeon And Region Matrix

## Design Position
The main dungeons should be treated as emotional and mechanical checkpoints, not just places where bosses happen.

## Current Critical-Path Matrix
- Lantern Heights First Missions: home, onboarding, belonging
- Summit Shrine: isolation, false elevation, scripted loss
- Weightbound Mines: exhaustion, Dash recovery
- Shatter Moth Nest: doubt, false paths, Double Jump recovery
- Stone Judge Maze: judgement, survival after cutoff, Glide recovery
- Hearth of Brothers: support structure, Grapple initiation
- Mentor Roga's Dojo: endurance training, Wall Cling progression
- Winding Skyroad Ascent: full-kit integration and vertical exposure
- Mirror Summit: Hollow Reflection confrontation and release
- Beacon of Return: ending and future-facing closure

## Use
Keep this folder aligned with boss planning, movement progression, and companion-return timing.
