# Main Dungeon And Region Matrix Index

## Checklist
- [ ] Keep each main dungeon tied to one clear emotional problem and one clear mechanical gain or test
- [ ] Track boss placement, ability unlocks, and companion-return beats against dungeon order
- [ ] Flag any new main dungeon that changes campaign scope or thematic pacing
- [ ] Keep region names, dungeon names, and their functions consistent across the GDD

## Drift Risks
- Main content can turn into a loose biome sequence if the matrix is not maintained
- Added dungeons can bloat the campaign without adding new emotional or mechanical meaning
