# Level And Content Plan

## Purpose
Describes the campaign content structure at a more production-usable level than the base Game World section.

## Why This Branch Exists
The original GDD scaffold covers world and levels conceptually, but the studio pack adds stronger planning detail around dungeon ordering, optional content types, and procedural room intent. This branch holds that material without overloading the narrative/world folders.

## What Belongs Here
- campaign content structure and taxonomy
- main dungeon and region planning
- optional content catalogs and constraints
- procedural room-intent planning
