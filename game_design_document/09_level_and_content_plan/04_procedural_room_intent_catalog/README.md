# Procedural Room Intent Catalog

## Design Position
Procedural rooms should be generated by intent, not only by geometry. The room's gameplay and narrative job should be known before layout detail is filled in.

## Current Intent Examples
- horizontal intro
- village social space
- veil mission
- scripted loss support
- cross gap dash proof
- double jump rise
- glide descent
- grapple crossing
- wall cling climb
- final ability gauntlet
- optional reward
- rest or save
- movement pressure
- boss arena

## Why This Matters
Intent-based generation is one of the clearest bridges between the Java lab prototype and a buildable campaign-grade content pipeline.
