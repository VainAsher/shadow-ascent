# Boss Design Template Index

## Checklist
- [ ] Keep template fields aligned with how the project actually evaluates bosses
- [ ] Preserve emotional meaning and restraint interaction as first-class fields
- [ ] Add fields only when they improve real design communication
- [ ] Revisit the template after the first fully specified boss docs exist

## Drift Risks
- A template that is too generic will not reflect this project's thematic combat design
- A template that is too detailed too early can slow authoring
