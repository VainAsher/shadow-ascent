# Boss Design Template

## Current Template Fields
Each boss spec should eventually include:
- name
- region
- emotional meaning
- required ability
- arena layout
- phase count
- core attacks
- defensive answer
- non-lethal or restraint interaction
- reward
- dialogue before and after
- hub effect
- QA notes

## Use
This is a reusable template for future boss-specific folders or external design docs.
