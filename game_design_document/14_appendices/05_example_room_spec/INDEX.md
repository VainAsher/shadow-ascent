# Example Room Spec Index

## Checklist
- [ ] Keep at least one example spec concrete enough to imitate directly
- [ ] Prefer examples that show mechanics, validation, and theme working together
- [ ] Update examples if the room-spec template changes substantially
- [ ] Add more examples only when they teach something new

## Drift Risks
- If examples are too abstract, they stop being useful
- If examples become outdated, they can teach the wrong format
