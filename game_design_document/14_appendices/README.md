# Appendices

## Purpose
Stores reusable supporting material that helps the GDD stay operational without bloating core sections.

## Why This Branch Exists
The studio pack includes templates, implementation checklists, and example spec structures that are useful reference material but should not sit inside the main authored narrative or systems branches.

## What Belongs Here
- one-page summaries
- implementation checklists
- reusable boss and room templates
- example specs
- source alignment notes
