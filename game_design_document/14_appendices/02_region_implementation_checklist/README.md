# Region Implementation Checklist

## Current Checklist Frame
Each major region should eventually account for:
- palette sheet
- tileset
- parallax background
- music layer
- ambience layer
- enemy family
- boss or major encounter
- save point style
- door or gate style
- ability gate signifiers
- NPC state rules
- plateau grammar
- optional room templates
- critical path validation
- narrative constraints
- map icons

## Use
This is a production-facing checklist, not a replacement for region fiction or level design.
