# Lifecycle Management Index

## Working Definitions
- `Draft`: usable but unsettled
- `In Review`: being actively validated
- `Approved`: canonical design truth
- `Implemented`: reflected in the game
- `Superseded`: intentionally replaced

## Topic Status Checklist
- [ ] Does this topic have enough clarity to leave Draft?
- [ ] Has the change been reviewed, not just written?
- [ ] If approved, does another document or implementation now depend on it?
- [ ] If implemented, does repo behavior still match the approved wording?
- [ ] If superseded, is the replacement path explicitly linked?

## Review Trigger Examples
- story beat changes
- pacing or difficulty philosophy changes
- character-function changes
- mechanical ability meaning changes
- world-structure changes
