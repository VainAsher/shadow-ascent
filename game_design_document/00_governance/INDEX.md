## Use This Folder In This Order
1. Read `01_lifecycle_management/` to understand document states.
2. Use `02_review_and_approval/` before treating a change as canonical.
3. Record major design movement in `03_change_log/`.
4. Record important reasoning in `04_decision_log/`.
5. Follow `05_contribution_workflow/` when updating the tree.

## Working Rule
If a design change is big enough to alter story, mechanics, pacing, or product framing, it should leave evidence in at least one of:
- change log
- decision log
- lifecycle state change
