# Change Log Index

## Entry Format
For each meaningful change, record:
- date
- affected topic(s)
- short summary of what changed
- whether the change is current-truth alignment or new direction
- linked decision log entry if one exists

## Use Checklist
- [ ] Would a future reader be confused if this change had no record?
- [ ] Did the meaning change, not just the wording?
- [ ] Were linked topics updated too?
