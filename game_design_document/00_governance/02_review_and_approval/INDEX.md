# Review and Approval Index

## Approval Checklist
- [ ] Is this change describing current truth, future direction, or both?
- [ ] If current truth, does it cite repo or canonical-doc evidence?
- [ ] If future direction, is it internally consistent with existing approved GDD material?
- [ ] Does this change require a decision-log entry?
- [ ] Does this change require related topics to be updated too?

## Escalation Cases
Create or update a decision-log entry when:
- two plausible directions exist
- a prior assumption is being reversed
- the change affects multiple domains
- the change could confuse future implementation if not explicitly justified
