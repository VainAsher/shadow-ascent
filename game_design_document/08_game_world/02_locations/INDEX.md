# Locations Index

## Checklist
- [ ] Keep the major locations list stable and clearly named
- [ ] Define the gameplay role, emotional role, and visual signature of each location
- [ ] Note which locations are hubs, traversal corridors, dungeons, reveals, or ending spaces
- [ ] Track any new location that changes progression, symbolism, or production scope

## Drift Risks
- Location sprawl will dilute the campaign's clear emotional geography
- Weak location roles will make regions feel interchangeable
