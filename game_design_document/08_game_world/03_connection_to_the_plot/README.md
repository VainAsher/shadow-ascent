# Connection to the Plot

## Region-to-Plot Function
- **Lantern Heights** proves that Aen belongs somewhere before the wound opens.
- **Summit Shrine** turns praise into possession and delivers the central loss.
- **The Hollow Depths** externalize depression, absence, and survival before healing.
- **Ember Monastery** makes support practical, structural, and communal.
- **The Winding Skyroad** tests whether recovery has become integrated strength.
- **Mirror Summit** stages the confrontation with the Hollow Reflection, the wound wearing Aen's shape.
- **Beacon Cliff** resolves the story through witness, release, and future rather than reversal.

## Plot Rule
No major location should exist only as scenery. Every major region must move Aen through the emotional sentence of the campaign:

`home -> praise -> isolation -> collapse -> numb survival -> grief -> support -> rebuilding -> ascent -> release -> future`

## Ending Constraint
Beacon Cliff should not hand back an unchanged past. Its function is to show that wholeness can exist without forcing the universe to undo the wound.
