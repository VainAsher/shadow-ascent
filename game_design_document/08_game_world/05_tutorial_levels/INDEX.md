# Tutorial Levels Index

## Checklist
- [ ] Define what the opening spaces must teach about movement, combat, belonging, and village life
- [ ] Keep onboarding embedded in Lantern Heights rather than detached from story context

## Drift Risks
- A tutorial that is too abstract will waste the strength of Lantern Heights as home
- A tutorial that is too dense will front-load systems before the player cares
