# Levels Index

## Checklist
- [ ] Define the level taxonomy: tutorial, hub-adjacent, dungeon, traversal ascent, optional challenge, and finale
- [ ] Keep level structure aligned with movement unlocks and emotional pacing
- [ ] Clarify what makes a level distinct from a named location or sub-area
- [ ] Track changes that affect critical-path length, backtracking load, or optional branch value

## Drift Risks
- Unclear level taxonomy will make production planning messy
- Over-fragmented levels can make the world feel stitched together instead of coherent
