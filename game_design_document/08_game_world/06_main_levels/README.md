# Main Levels

## Critical Path Structure
The studio pack clarifies a strong main-level taxonomy for the campaign:
- Lantern Heights First Missions
- Summit Shrine
- Weightbound Mines
- Shatter Moth Nest
- Stone Judge Maze
- Hearth of Brothers
- Mentor Roga's Dojo
- Winding Skyroad Ascent
- Mirror Summit
- Beacon of Return

## Design Reading
These are not just biome names. Each main level should carry a distinct emotional and mechanical job:
- home and onboarding
- isolation and scripted wound
- survival and first motion return
- doubt and second reach
- judgement and surviving the fall
- support becoming structure
- endurance training
- full-kit ascent
- final self-confrontation and release
- quiet ending resolution

## Practical Value
This list helps the GDD move from vague regional description toward a production-usable critical path. It also makes it easier to map bosses, ability unlocks, and NPC returns against the main campaign.
