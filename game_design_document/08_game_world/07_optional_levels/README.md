# Optional Levels

## Design Position
Optional levels should deepen character, mastery, atmosphere, and lore without carrying the irreplaceable core emotional truth of the campaign. They are a support layer, not the real spine.

## Strong Optional Content Types
- memory echo rooms
- NPC quest rooms
- combat trial rooms
- movement mastery rooms
- hidden relic rooms
- lore tablet chambers
- shortcut unlock rooms
- environmental puzzle rooms
- boss remembrance arenas

## Constraints
- optional content must not restore Yin and Yang
- optional content must not replace critical boss progression
- optional content must not contradict story order or plateau tone
- optional content must not require co-op on the main solo path
- optional content must not create ability softlocks

## Design Reading
This is a useful clarification because it protects the project from a common failure mode: adding side content that is mechanically interesting but narratively corrosive. Optional spaces should enrich the journey, not overwrite it.
