# Optional Levels Index

## Checklist
- [ ] Define what optional content adds: lore, challenge, economy, mastery, or emotional reflection
- [ ] Keep optional levels meaningful without making them mandatory for thematic comprehension
- [ ] Clarify which rewards are cosmetic, supportive, or progression-adjacent
- [ ] Track any optional branch that risks contradicting canon or flattening pacing

## Drift Risks
- Optional content can bloat scope if it is not held to a clear purpose
- Optional content that carries essential emotional truth will make the main path feel incomplete
