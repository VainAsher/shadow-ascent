# Runtime Architecture

## Design Position
The game should be thought of as cooperating modules rather than one undifferentiated gameplay layer.

## Current Architecture Frame
The strongest current module map is:
- game core
- entity system
- movement system
- combat system
- stealth system
- narrative state
- procgen system
- level streaming
- UI system
- audio system
- save system
- tooling and validation

## Use
This topic should stay high-level. It is for design-to-engine coordination, not low-level code diagrams.
