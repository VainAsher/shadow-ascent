# Narrative Validation System

## Design Position
Narrative truth in this project should be enforceable, not just aspirational.

## Current Validation Cases
Generation or content validation should fail when:
- Yin and Yang appear as active companions after the scripted loss
- a room grants a forbidden story outcome
- a route requires an unavailable ability
- a boss appears in the wrong plateau
- light state contradicts act state
- NPC role contradicts story flags
- optional content advances main story truth
- Beacon resolution appears before Hollow Reflection release

## Why This Matters
This is one of the game's strongest differentiators. The emotional arc is fixed enough to be validated even while rooms and optional content remain elastic.
