# Narrative Validation System Index

## Checklist
- [ ] Keep forbidden states and impossible story transitions explicit
- [ ] Tie validation rules to plateau, act, NPC role, ability, and ending-state logic
- [ ] Record which validation failures are hard errors versus debug warnings
- [ ] Review this topic whenever story sequencing or procgen rules change

## Drift Risks
- Without validation, elastic content can quietly break the game's most important canon
- Overly brittle validation can block harmless iteration if rules are not scoped well
