# Entity Component Model

## Design Position
The project is best served by composable entities rather than large one-off inheritance hierarchies.

## Strong Current Component Set
- transform
- render layer
- collision body
- hurtbox
- hitbox
- health or resolve
- posture or stun
- faction
- AI behavior
- inventory
- interaction
- dialogue
- quest giver
- save anchor
- ability gate
- audio emitter
- light emitter
- narrative tag

## Use
This topic should map recurring gameplay needs across player, NPCs, enemies, bosses, interactables, hazards, and world objects.
