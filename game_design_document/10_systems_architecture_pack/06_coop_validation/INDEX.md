# Co-Op Validation Index

## Checklist
- [ ] Keep solo completion of the critical path non-negotiable
- [ ] Mark where co-op changes room validation, camera logic, or respawn handling
- [ ] Track whether co-op is launch-facing, internal-only, or deferred
- [ ] Record any mechanic that becomes impossible or trivial with multiple players

## Drift Risks
- Soft multiplayer promises can create hidden scope creep
- Co-op assumptions can break narrative pacing if not tightly contained
