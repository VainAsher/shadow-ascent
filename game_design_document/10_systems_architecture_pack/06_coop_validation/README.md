# Co-Op Validation

## Design Position
The project is solo-first. Any co-op support must validate against that truth instead of distorting it.

## Current Safe Rules
- the main critical path must remain completable by one player
- optional co-op rooms should be clearly marked and isolated
- story ownership should remain with the host or primary save owner
- NPC dialogue should continue to treat Aen as the narrative anchor
- camera, respawn, and traversal rules should prevent griefing or deadlock

## Why This Branch Matters
The studio pack raises co-op as a validation concern, but not as a reason to redesign the campaign around multiplayer dependence.
