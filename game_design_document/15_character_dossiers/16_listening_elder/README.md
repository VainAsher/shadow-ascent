# Listening Elder

## Core Identity
- Listening Elder is the validation-without-pressure figure who gives Aen space to name pain without being corrected out of it.

## Narrative Function
- The Elder stabilizes the emotional logic of grief by making being heard a gameplay-relevant form of support.

## Concrete Behaviors
- offers reflection dialogue, memory rest, or quiet conversation nodes
- receives Aen's pain without immediately reframing or fixing it
- clarifies that witness can matter before solutions do

## Gameplay Impact
- supports low-pressure rest, lore interpretation, or journal clarification surfaces
- gives the player emotional decompression points that are distinct from upgrade or combat rewards
- can unlock memory codex entries, dialogue recap, or reflective checkpoints

## System Dependencies
- dialogue/rest interfaces
- memory or journal systems
- support-state conversations

## Failure Mode
- Listening Elder fails if validation is only thematic and never changes how rest or reflection spaces function.
