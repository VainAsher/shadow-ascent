# Smith Monk

## Core Identity
- Smith Monk is the first practical-support figure after collapse, combining repair discipline with quiet motion coaching.

## Narrative Function
- The Smith Monk turns the return of Dash into help received rather than power reclaimed through will alone.

## Concrete Behaviors
- repairs or adjusts what Aen needs to move again
- provides the first practical movement challenge after collapse
- restores Dash through an encounter framed as readiness, not inspiration

## Gameplay Impact
- anchors the first major recovery ability in a support relationship
- gives Dash a clean emotional meaning: movement returns through practical help
- supports early Hollow Depths progression and first real agency after collapse

## System Dependencies
- Dash unlock sequencing
- Hollow Depths quest or encounter gating
- repair/support dialogue and interaction

## Failure Mode
- Smith Monk fails if Dash reads like a normal upgrade drop instead of a support-driven return of motion.
