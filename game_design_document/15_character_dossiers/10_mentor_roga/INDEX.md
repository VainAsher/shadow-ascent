# Mentor Roga Index

## Checklist
- [x] Core identity is stated clearly
- [x] Narrative function is explicit
- [x] Symbolic meaning is present but concise
- [x] Observable behaviors are listed
- [x] Gameplay consequences are explicit
- [x] Linked quests, encounters, or tutorials are named
- [x] Act-by-act state changes are tracked
- [x] Related systems are named
- [x] Overlap with nearby characters is controlled
- [x] Failure mode is documented

## Drift Risks
- Roga becomes a generic hard mentor if endurance drills and wall-cling mastery are not experiential.
- Difficulty reads as cruelty instead of trained persistence if his presence inside pain is underdefined.
- He overlaps Samson if courage under pressure is not separated from disciplined repetition.
- He overlaps Marcel if structural toughness is not distinguished from body-and-breath endurance.
