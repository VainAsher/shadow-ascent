# Hearth Brother

## Core Identity
- Hearth Brother is the welcoming face of monastery support: warmth turned into repeatable structure.

## Narrative Function
- He makes Ember Monastery feel like a system of care, not a single mentor cutscene.

## Concrete Behaviors
- receives Aen into the monastery without demanding immediate wholeness
- anchors shared meals, safe warm spaces, and first support-hub routines
- introduces monastery structures that make later training and recovery feel communal

## Gameplay Impact
- helps the player read Ember Monastery as a recoverable hub rather than only a quest stop
- supports hub warmth, rest, and social structure after Hollow Depths isolation
- can unlock first monastery refuge functions or support-hub services

## System Dependencies
- Ember Monastery hub scripting
- refuge/rest identity
- social support routines

## Failure Mode
- Hearth Brother fails if Ember Monastery feels mechanically useful but emotionally impersonal.
