# Old Man Riku

## Core Identity
- Old Man Riku is the living memory of Lantern Heights and a witness to who Aen was before the wound.

## Narrative Function
- Riku keeps "home" from meaning only current geography by tying it to remembered identity and older warnings.

## Concrete Behaviors
- recalls earlier village patterns, shrine stories, or past warnings others overlook
- names who Aen was before collapse and praise-based isolation
- can deliver memory-heavy dialogue that anchors the emotional cost of the village changing

## Gameplay Impact
- supports pre-wound identity framing and deeper home memory
- can unlock older lore, warning dialogue, or return-value scenes when Lantern Heights changes
- helps the player feel that what was lost includes continuity, not just companionship

## System Dependencies
- village memory dialogue
- lore/warning scenes
- return-to-hub state changes

## Failure Mode
- Riku fails if home has no living memory and becomes only scenery.
