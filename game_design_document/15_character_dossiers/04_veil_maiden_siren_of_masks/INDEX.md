# Veil Maiden / Siren of Masks Index

## Checklist
- [x] Core identity is stated clearly
- [x] Narrative function is explicit
- [x] Symbolic meaning is present but concise
- [x] Observable behaviors are listed
- [x] Gameplay consequences are explicit
- [x] Linked quests, encounters, or tutorials are named
- [x] Act-by-act state changes are tracked
- [x] Related systems are named
- [x] Overlap with nearby characters is controlled
- [x] Failure mode is documented

## Drift Risks
- The Siren becomes a flat evil temptress if praise, specialness, and mission framing are not operationalized.
- The Hollowing wound loses structure if she does not clearly reorganize quests, tone, and isolation.
- Summit Shrine loses force if her reveal feels like a twist instead of the endpoint of a designed social separation.
- She overlaps Hollow Reflection if she is treated as the final emotional problem instead of the author of it.
