# Brother Len

## Core Identity
- Brother Len is the patience-and-timing support who teaches measured control inside recovery.

## Narrative Function
- Len gives the monastery a technical, breath-aware support lane distinct from force or endurance.

## Concrete Behaviors
- teaches timing, breath pacing, and measured repetition
- helps Aen slow down enough to learn precision rather than panic
- supports technical drills where success depends on rhythm rather than brute persistence

## Gameplay Impact
- can support precision tutorial spaces, timing checks, or patience-based challenge rooms
- balances more forceful mentors by owning calm technical correction
- helps frame later mastery as control, not just intensity

## System Dependencies
- monastery drill content
- timing/patience challenge scripting
- support dialogue

## Failure Mode
- Len fails if precision training has no personal owner and blends into generic tutorial text.
