# Shade Hermit

## Core Identity
- Shade Hermit is the underworld witness who knows how to survive hollow places without pretending they are healed.

## Narrative Function
- The Hermit stabilizes the Hollow Depths as a survival phase rather than a quick redemption arc.

## Concrete Behaviors
- provides sparse orientation through the underworld without over-explaining grief
- marks survival-safe pockets, warns against false exits, and names endurance before hope
- frames living through collapse as a valid stage rather than a failure to recover fast enough

## Gameplay Impact
- supports Hollow Depths navigation, pacing, and emotional interpretation
- helps the player distinguish survival rooms from progress fantasies
- can gate key underworld guidance, sparse checkpoint knowledge, or non-combat witness dialogue

## System Dependencies
- Hollow Depths dialogue
- survival-space signaling
- underworld navigation support

## Failure Mode
- Shade Hermit fails if they become a generic spooky lore NPC instead of a survival witness.
