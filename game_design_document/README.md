## How To Read This First Pass
- `repo-backed truth` means the current clean-start repo already implements or explicitly documents it.
- `donor signal` means the donor projects strongly indicate intended direction, but the clean-start repo may not fully implement it yet.
- `studio-pack clarification` means the external GDD pack sharpens intent, structure, production scope, or systems language beyond what the repo alone proves.
- `unresolved` means the projects do not currently justify a stronger claim without new design decisions.

## Extended Branches
The original scaffold followed the Indie Game Academy structure. The GDD now also includes studio-facing branches for:
- level and content planning
- character dossiers
- systems architecture
- production scope and roadmap
- QA, telemetry, and acceptance criteria
- risks and open questions
- appendices and reusable templates

These branches exist so production-useful material has a stable home instead of being forced into the narrower original template.

Use `15_character_dossiers/` to document the cast by in-play behavior and gameplay consequence, not only by symbolic meaning.
