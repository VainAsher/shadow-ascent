# Production Scope And Roadmap

## Purpose
Defines how to ship the project without losing its identity to scope creep.

## Why This Branch Exists
The studio pack adds practical planning content that does not belong inside gameplay or world folders: scope rules, vertical slice targets, milestone framing, and MVP boundaries.

## What Belongs Here
- scope control decisions
- vertical slice framing
- milestone structure
- must-have versus deferable features
