# MVP Feature Set Index

## Checklist
- [ ] Keep must-have features tied to release identity, not wishful completeness
- [ ] Separate must, should, could, and deferred categories clearly
- [ ] Review this list whenever a major mechanic or platform commitment changes
- [ ] Use this topic to challenge scope creep with evidence

## Drift Risks
- MVP inflation will make release planning meaningless
- Aggressive cuts can also break the game's identity if they remove too much of the emotional spine
