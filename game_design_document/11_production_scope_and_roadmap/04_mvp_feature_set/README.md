# MVP Feature Set

## Current MVP Reading
The first release should include:
- complete campaign critical path
- core movement kit
- combat with lethal and non-lethal expression
- stealth basics
- hubs and hub-state changes
- main NPC quest beats
- key bosses through Hollow Reflection
- Beacon ending
- save/load
- map or journal support
- accessibility basics
- debug validation tools

## Critical Review Note
This list is probably too large to serve as a true MVP. It currently reads closer to a campaign alpha or near-ship scope than a minimum viable product.

## Recommended Scope Split
- **Vertical Slice Must-Have**: enough content and systems to prove movement, emotional hook, one support loop, one real wound transition, and one procedurally valid optional room
- **Campaign Alpha Must-Have**: full critical path with placeholder content acceptable
- **Ship Target Must-Have**: the actual release bar, including polish, accessibility, and final-end experience

## Should Have
- optional generated rooms by plateau
- ending tone variation
- boss remembrances
- environmental puzzles

## Deferred By Default
- separate arcade or sandbox products
- MMO-style multiplayer ambition
- endless open-world simulation
- fully procedural main story

## Designer Questions
- Which items in the current list are truly required to prove the fantasy to outsiders?
- Which items are required only for a full campaign alpha?
- Which systems can remain partially stubbed in the vertical slice without breaking the pitch?
