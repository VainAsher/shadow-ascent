# Vertical Slice Target Index

## Checklist
- [ ] Keep the slice small enough to finish and rich enough to prove the core fantasy
- [ ] Track which parts are mandatory for external presentation versus internal validation
- [ ] Note what the slice must prove emotionally, mechanically, and technically
- [ ] Record any slice expansion that risks turning it into a soft alpha

## Drift Risks
- A slice that proves too little will not de-risk the project
- A slice that proves everything will never ship as a slice
