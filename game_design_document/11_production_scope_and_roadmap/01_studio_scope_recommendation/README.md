# Studio Scope Recommendation

## Core Recommendation
Ship one strong campaign before expanding into standalone modes, large multiplayer promises, or heavy simulation systems.

## Keep
- campaign
- Aen's full emotional arc
- major regions
- movement mastery
- combat expression
- hub evolution
- procedural-assisted optional content
- debug and validation tooling

## Cut Or Defer
- standalone arcade mode
- standalone sandbox mode
- large multiplayer world promises
- complex economy simulation
- infinite quest sprawl
- excessive gear systems before core feel is proven
