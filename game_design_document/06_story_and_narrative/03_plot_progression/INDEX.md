# Plot Progression Index

## Checklist
- [ ] Keep the campaign phase order readable from start to finish
- [ ] Tie each major region and boss to a clear emotional and mechanical progression beat
- [ ] Note where pacing should linger, accelerate, or deliberately deny relief
- [ ] Track any sequence change that affects ability provenance, returning companions, or ending setup

## Drift Risks
- Progression beats that move too quickly will cheapen the recovery arc
- Region order changes can accidentally break the emotional logic behind the movement kit
