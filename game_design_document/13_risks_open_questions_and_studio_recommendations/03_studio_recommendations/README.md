# Studio Recommendations

## Core Recommendation
Protect the project's identity ruthlessly. The most distinctive part of Shadow Ascent is not "ninja Metroidvania" by itself, but the combination of:
- movement as healing
- hub state as emotional truth
- combat expression as self-definition
- procedural rooms constrained by authored grief stages
- an ending built on wholeness without reversal

## Working Test
Every major feature should answer one question:

Does this help the player feel Aen becoming whole without undoing what happened?

If not, it is probably scope noise.
