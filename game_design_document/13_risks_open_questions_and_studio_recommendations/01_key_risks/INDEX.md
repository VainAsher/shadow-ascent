# Key Risks Index

## Checklist
- [ ] Keep the top project risks ranked by actual threat, not by how often they are discussed
- [ ] Pair each risk with at least one mitigation or containment plan
- [ ] Review this list when scope, platform, or content strategy changes
- [ ] Move resolved risks into governance history if they stop being active concerns

## Drift Risks
- If risks are not named plainly, they will survive as background noise
- If every concern is labeled critical, real priorities disappear
