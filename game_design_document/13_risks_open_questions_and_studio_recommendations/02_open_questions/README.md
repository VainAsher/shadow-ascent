# Open Questions

## Current Strong Questions
### Immediate Designer Questions
- final public title choice
- whether Flow is visible, subtle, or late-game
- whether Lantern is a resource, tool, or mainly symbolic amplifier
- final art resolution choice
- what minimum public-facing slice should be shown

### Scope And Production Questions
- whether co-op is launch-facing or only technically validated
- how many ending tone variants are production-realistic
- how many mandatory bosses fit first release

### Narrative And System Questions
- how redeemable or ambiguous the Veil Maiden should remain
- how much dialogue choice fits without turning the game into a branching RPG

## Why These Questions Matter
- some of these are product-positioning questions
- some are implementation blockers
- some are polish or thematic-clarity questions

They should not be treated as equally urgent.

## Recommended Review Order
1. MVP and public-slice questions
2. art-format and systemic-UI questions
3. co-op commitment
4. ending/boss count
5. Veil Maiden ambiguity and dialogue branching
