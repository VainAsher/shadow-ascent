# Game Options

## Design Rule
Options should respect the fact that Shadow Ascent is a game about emotional readability, movement precision, and player orientation. Configuration should help players access the intended experience, not force everyone into one rigid presentation.

## Expected Option Categories
- audio volume controls
- input rebinding and controller support
- camera or screen-comfort settings where needed
- accessibility and readability assists
- UI scale or clarity options
- gameplay forgiveness options if later difficulty/accessibility systems support them

## Highest-Priority Options
If scope is limited, the most important option surfaces are:
- rebinding for movement/combat/interact actions
- music/SFX balance
- minimap/HUD readability
- screen shake or motion intensity control if added later
- text speed or dialogue readability controls

## Accessibility Position
Accessibility should be treated as part of the game's thematic integrity, not an optional afterthought. A game about grief, support, and return should make room for players to reach its core meaning through readable and configurable systems.

## Current Limitation
The repo does not yet prove a finished options menu. This section describes what the shipped game should support, not what is already exposed in polished form.
