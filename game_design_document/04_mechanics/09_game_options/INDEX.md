# Game Options Index

## Checklist
- [ ] List graphics, audio, control, accessibility, language, and gameplay comfort options
- [ ] Separate shipped options from aspirational ones to avoid false promises
- [ ] Keep accessibility and readability options tied to actual player pain points in the current build
- [ ] Record any option whose absence would materially limit testing or player comprehension

## Drift Risks
- Writing options as if they already exist will make the GDD less trustworthy
- Treating accessibility as an afterthought will create expensive retrofits later
