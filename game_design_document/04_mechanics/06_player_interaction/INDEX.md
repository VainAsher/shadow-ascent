# Player Interaction Index

## Checklist
- [ ] Enumerate interaction types: dialogue, pickup, shrine, lever, shop, crafting, stealth, combat, and traversal surfaces
- [ ] Clarify which interactions are contextual, menu-driven, automatic, or ability-gated
- [ ] Keep interaction readability and input burden aligned with the current control scheme
- [ ] Note any interaction that changes meaning across regions or emotional states

## Drift Risks
- Too many inconsistent interaction rules will make the world feel arbitrary
- Overuse of one-button context actions can erase meaningful differences between systems
