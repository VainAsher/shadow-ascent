# Economy Index

## Checklist
- [ ] Define all currencies, sinks, upgrade costs, and recovery loops currently planned or implemented
- [ ] Explain how economy supports progression without overshadowing emotional and exploration rewards
- [ ] Clarify what can be bought, crafted, earned through quests, or permanently missed
- [ ] Flag any economy assumptions that could break pacing or trivialize challenge

## Drift Risks
- Too much economic weight can make the game feel like a shop treadmill instead of a healing journey
- Too little economic structure can make crafting, merchants, and reward loops feel cosmetic
