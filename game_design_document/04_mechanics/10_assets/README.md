# Assets

## Core Asset Categories
Shadow Ascent depends on several major asset groups:
- player character visuals and animation states
- spirit-orb visual states for Yin and Yang
- enemy and boss visuals
- tilesets and traversal geometry art
- environmental props and landmark assets
- interface and HUD assets
- audio assets including music, ambience, and SFX
- narrative presentation assets such as portraits, symbols, masks, and beacon motifs

## Current Runtime Reality
The repo currently proves more asset architecture than finished asset inventory. There is active movement toward a production client and asset pipeline, but the visible game is still placeholder-heavy.

## Asset Philosophy
Assets should reinforce the game's emotional architecture:
- warmth versus hollow cold
- repair versus fracture
- ascent versus compression
- sacred beauty versus trap-like symmetry
- support versus isolation

## Priority Asset Groups
If production asset work has to be staged, the highest-value groups are:
- player/NPC/enemy readability assets
- environment tiles and landmark identity
- HUD and minimap clarity assets
- musical and ambient identity

These will do more for the player-facing game than deep optional cosmetic breadth early on.

## Pipeline Note
The project will eventually need a real asset pipeline for packing, loading, and rendering. Until that is complete, this section should stay focused on categories and function rather than pretending the final inventory is already stable.
