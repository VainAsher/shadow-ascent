# Game Menus Index

## Checklist
- [ ] List all menu surfaces the player can open and the purpose of each
- [ ] Define expected navigation depth, controller or keyboard flow, and pause-state behavior
- [ ] Clarify which systems belong in menus versus in-world interaction
- [ ] Keep menu structure aligned with inventory, map, quests, crafting, options, and save behavior

## Drift Risks
- Menu sprawl will slow down a game that depends on movement rhythm and clarity
- Missing boundaries between menu and diegetic interactions will confuse feature ownership
