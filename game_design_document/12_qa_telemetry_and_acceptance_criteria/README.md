# QA Telemetry And Acceptance Criteria

## Purpose
Captures how the project should be tested, what should be observed, and what "good enough" means for major systems.

## Why This Branch Exists
The base GDD describes intent. This branch describes verification, test focus, and operational quality thresholds without forcing them into governance or gameplay sections.

## What Belongs Here
- QA priority areas
- useful telemetry targets
- acceptance criteria for movement, combat, narrative, and procgen
