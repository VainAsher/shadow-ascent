# Telemetry Targets

## Safe Design Position
Telemetry should be privacy-conscious and used to improve clarity, fairness, and pacing rather than flatten intended discomfort.

## Strong Current Targets
- death locations
- failed traversal attempts
- boss attempts
- ability usage frequency
- lethal versus non-lethal outcomes
- save/load error rates
- time to first Dash
- time spent in Hollow Depths before Ember Monastery
- optional room completion rate
- quit points

## Use
This topic should guide internal observation and tuning, not assume a public live-service analytics program.
