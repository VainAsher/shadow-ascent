# QA Priorities

## Core QA Areas
- movement collision and traversal reliability
- ability unlock order
- save and load integrity
- boss state persistence
- region transitions
- map and UI prompts
- dialogue and NPC state triggers
- Yin and Yang narrative constraints
- procedural reachability and softlock prevention

## Design Reading
This game needs three QA lenses at once:
- functional QA for controls and systems
- narrative QA for canon and state correctness
- procedural QA for seed safety and room validity
