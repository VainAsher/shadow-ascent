# Look and Feel

## Core Feel Statement
Shadow Ascent should feel like a wounded spiritual mountain epic in which platforming, combat, and world progression are always carrying emotional meaning. The player should feel the difference between warmth, flattery, isolation, grief, support, ascent, release, and wholeness, not just read about those states in dialogue.

## Emotional Campaign
The whole game should be legible through this sentence:

`home -> praise -> isolation -> collapse -> numb survival -> grief -> support -> rebuilding -> ascent -> release -> future`

## Visual And Tonal Direction
- Lantern warmth, communal lantern light, wood, cloth, bridges, and terraces
- Shrine beauty that becomes sterile, symmetrical, and trap-like
- Hollow cold, damp compression, broken supports, black water, and almost-light
- Ember warmth that feels chosen and repaired rather than innocent
- Exposed high-altitude ascent, bells, clouds, stars, and dangerous openness
- Final sacred stillness at the beacon

## Narrative Feel Rule
This is not a revenge fantasy and not a reunion fantasy. The ending should feel earned because it refuses easy reversal. The player's strongest emotional reward is not "everything came back." It is "Aen became whole anyway."
