# Game Music Index

## Checklist
- [ ] Define the musical identity of Lantern Heights, Hollow Depths, Ember Monastery, Skyroad, and Beacon Cliff
- [ ] Clarify when themes should evolve, fracture, or return across the campaign
- [ ] Keep the Yin and Yang absence/presence logic reflected in the score where possible
- [ ] Separate required musical functions from ideal soundtrack ambitions

## Drift Risks
- Music that treats every region as a mood board will miss the narrative arc
- Overly busy scoring can compete with stillness, which this game needs
