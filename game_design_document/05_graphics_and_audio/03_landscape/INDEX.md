# Landscape Index

## Checklist
- [ ] Describe how each major region communicates its emotional state through shape, color, density, and landmarking
- [ ] Keep traversal readability and navigation memory stronger than raw detail density
- [ ] Define what environmental repetition is acceptable in prototype content versus shipping content
- [ ] Link landscape notes to locations, levels, and world-structure assumptions

## Drift Risks
- Landscapes that read only as biomes will lose the inner-life metaphor driving the game
- Excess visual clutter will harm route reading in traversal-heavy spaces
