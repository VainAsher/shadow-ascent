# Interface Index

## Checklist
- [ ] List every player-facing HUD and menu element that must remain visible or accessible during play
- [ ] Define how the interface communicates health, spirit state, quests, economy, minimap, and progression
- [ ] Separate critical signal from optional flavor so the screen stays readable

## Drift Risks
- HUD growth can crowd the playfield and weaken the game's atmosphere
- Under-signaled systems will make progression and player intention harder to read
