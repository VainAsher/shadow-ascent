## Style Baseline

- Hybrid high-resolution 2D concept art
- Side-scrolling Metroidvania readability
- Hand-painted fantasy rendering
- Strong silhouette separation
- No UI, no text, no watermark

- Set 02 adds one boss arena mood key, one antagonist concept sheet, and one production-useful tileset sheet.

- If you want the next pass after this, the highest-value addition is `Siren of Masks`, `Save Room / Refuge Variants`, or a dedicated `symbol set` pass for masks, bells, seals, shrine icons, and orb motifs.
