# Visual System Index

## Checklist
- [ ] Define the target rendering language, palette logic, silhouette priorities, and lighting mood by phase of the journey
- [ ] Separate proven prototype visuals from aspirational production style
- [ ] Keep visual decisions aligned with readability first, atmosphere second, and spectacle third
- [ ] Record any major style change that would affect UI, environment, or animation planning

## Drift Risks
- A style document that is too generic will not guide actual art decisions
- A style document that overcommits too early may constrain practical asset production
