# Audio Look And Feel Index

## Checklist
- [ ] State what the game should sound like emotionally at each major phase of Aen's journey
- [ ] Define the contrast between warmth, hollowness, ember recovery, ascent, and release
- [ ] Keep sound identity aligned with narrative truth rather than generic fantasy atmosphere
- [ ] Record any sound motifs that should recur for key characters, spirits, or bosses

## Drift Risks
- Generic mystical audio direction will blur the project's emotional specificity
- If every region sounds equally dramatic, the recovery arc will flatten
