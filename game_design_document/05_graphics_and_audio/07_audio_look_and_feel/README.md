# Audio Look and Feel

## Core Audio Goal
Audio should make the player feel the difference between warmth, flattery, isolation, grief, support, ascent, confrontation, and release even before any line of dialogue explains it.

## Audio Texture By Emotional State
- **Warmth**: living lantern spaces, cloth, wood, foot traffic, breath, bells, community presence
- **Praise / Shrine Seduction**: beauty, symmetry, distance, ritual, too-clean resonance
- **Isolation / Hollowing**: thinner ambience, broken echoes, absence where sound should be
- **Grief / Survival**: weight, dampness, distant movement, pressure, cold resonance
- **Support / Rebuilding**: hearth sound, tools, soft voices, steadier air, human rhythm
- **Ascent**: wind, height, openness, exposed bells, distant stars
- **Release**: reduced pressure, clarity, stillness, sacred spaciousness

## Sound-Design Rule
Audio should not only react to combat. It should react to:
- the state of a place
- the presence or absence of support
- ability restoration and movement confidence
- world mutation or narrative pressure

## Final Tone
The ending should not sound triumphant in a conquest-heavy sense. It should sound open, sacred, and earned. The player should feel that something has been released, not merely defeated.

## Current Limitation
This is a target emotional specification, not implemented audio truth. The game still lacks a finished audio stack.
