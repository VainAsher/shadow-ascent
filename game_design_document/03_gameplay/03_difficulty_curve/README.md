# Difficulty Curve

## Core Curve
The difficulty curve should track Aen's emotional journey as much as raw mechanical escalation. Early challenge should feel legible and safe enough to teach belonging and baseline confidence. Midgame challenge should feel disorienting, heavy, and fractured. Later challenge should test integrated mastery rather than simple survival panic.

## Region-Based Curve
- **Lantern Heights**: low-to-moderate difficulty; teaching movement, combat rhythm, and social orientation
- **Summit Shrine**: controlled spike; rising tension, narrowing routes, emotional unsettlement, scripted defeat
- **Hollow Depths**: sustained survival difficulty; heavier traversal, harsher rooms, lower player confidence, gradual recovery
- **Ember Monastery**: challenge remains real, but support structures make skill growth feel stable rather than punishing
- **Winding Skyroad**: high mechanical demand; full-kit traversal and integrated expression
- **Mirror Summit**: peak challenge through synthesis, mirroring, and emotional pressure
- **Beacon Cliff**: release of tension rather than a final mechanical spike

## What The Curve Should Feel Like
The curve should not read as a smooth RPG stat climb. It should feel more like:
- confidence
- rupture
- survival
- rebuilding
- integration
- reckoning
- release

## Adaptation Rule
The game does not need a highly dynamic adaptive AI difficulty model to succeed. The stronger design goal is authored difficulty that respects the narrative arc. Optional content can provide challenge variance, but the main route should remain emotionally and mechanically legible.

## Failure Philosophy
Failure in Hollow Depths should feel exhausting but survivable. Failure in Skyroad should feel like a mastery check. Failure at Mirror Summit should feel like confronting the self, not like being stat-blocked by arbitrary inflation.
