# Difficulty

## Default Position
Shadow Ascent should be tuned first around one well-authored default experience rather than many early difficulty permutations. The priority is to make movement, combat pressure, and emotional pacing coherent on the main route.

## Tuning Levers
If difficulty settings are offered later, they should primarily adjust:
- damage tolerance
- encounter forgiveness windows
- checkpoint generosity
- recovery-item abundance
- assistive readability features

They should avoid breaking the intended relationship between emotional tone and challenge structure.

## What Should Stay Constant
Across difficulty variants, the following should remain true:
- Summit Shrine still feels like a controlled collapse
- Hollow Depths still feels heavy and survival-oriented
- Ember Monastery still feels like stabilizing recovery
- Skyroad still demands integrated mastery
- Mirror Summit still feels like a final reckoning

## Recommended Philosophy
Accessibility and readability should be preferred over macho difficulty signaling. A game about grief, support, and wholeness should make room for different players to reach its thematic core without flattening its mechanical identity.

## Current Limitation
The repo does not yet prove a final difficulty-settings menu or live tuning model. This section should be treated as direction for future balancing and accessibility work, not a claim that multiple polished difficulty modes already exist.
